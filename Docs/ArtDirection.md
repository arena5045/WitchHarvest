# 마녀의 수확제 — 아트 및 UI 방향

기준: 2026-11-25 / 개발 버전 0.45. 게임의 세계관과 성격은 [GameDesign](GameDesign.md)을 참고한다. 이 문서는 아트를 새로 제작하거나 화면을 수정할 때 참조하는 방향이며, 기존 시안 중 최종 채택되지 않은 요소를 강제하지 않는다.

## 1. 전체 톤

귀여운 마녀, 신비로운 마법 농장, 정중하고 위엄 있는 대악마가 함께하는 따뜻하고 유쾌한 판타지. 보랏빛 밤, 따뜻한 등불, 목재와 식물, 마법 효과가 어우러진 PC 인디게임 감성. 공포·고어보다는 아늑함과 캐릭터 대비를 강조한다.

- 2D 애니메이션풍 캐릭터 일러스트와 읽기 쉬운 UI.
- 보라·회보라·차콜 계열과 바랜 황동/따뜻한 금빛, 크림색 텍스트를 활용할 수 있다. 마법의 보라색, 호박의 주황빛, 식물 녹색 등 기능과 환경에 맞는 포인트를 준다. 팔레트는 방향이지 고정 색상 코드가 아니다.
- 색상 수와 장식 밀도를 절제한다. 지나치게 화려한 금장, 과한 장식, 불필요한 디테일, 너무 높은 채도를 피한다.
- 제목/주요 행동/보조 정보의 위계를 분명히 한다. 모바일 게임풍의 복잡한 버튼 장식이나 작은 글씨를 지양한다.

## 2. 캐릭터 디자인 기준

**리엘(Riel)** — 은백색~연보라 머리, 보라색 눈, 마녀 모자와 망토가 특징인 견습 마녀. 귀엽고 발랄한 표정. 기존 스탠딩의 실루엣, 의상, 색감 및 캐릭터성을 보존한다.

**세르(Ser)** — 거대한 검은 털의 짐승 같은 몸, 흰 사슴 해골 얼굴, 보라색 눈, 큰 뿔, 손톱, 단정한 정장. '괴물의 얼굴을 한 신사'. 원본 시안의 외알안경, 따뜻한 뿔 등불, 보랏빛 장식, 절제된 금장 등 기존 특징을 참고한다. 원본과 상체 폭을 넓힌 수정 시안은 모두 보관 중이며 최종 선택은 미정. 체형을 보완하더라도 옷 장식을 과도하게 늘리지 않는다. 위엄은 금장과 체인 증량보다 체격·자세·눈빛으로 표현한다.

**레니아(Lenia)** — 은백색 긴 머리, 앤틱 골드 눈, 차콜·회보라 로브와 바랜 황동 장식의 대마녀. 고대 마법·연금술의 기하학적 인장과 절제된 장식 방향. 잎사귀나 밀 이삭 문양을 의상 전반에 반복하지 않는다.

표정·자세나 그림체만 바꾸는 요청에서는 수정 대상 이외의 외형, 색상, 의상 디테일과 소품을 보존한다. 기존 캐릭터 간 화풍을 일치시키고, 신규 장식을 임의로 추가하지 않는다. 스탠딩/스프라이트는 필요한 경우 투명 배경을 유지하며, 표정 변경으로 기준 위치나 크기가 크게 달라지지 않게 한다.

## 3. 작물, 이펙트와 농장

도망무는 흰 무 몸체와 녹색 잎, 표정으로 귀여운 요괴 작물 느낌을 낸다. 후속 작물은 작은 크기에서도 구분할 수 있는 실루엣과 특색을 우선한다. 본체, 흙 타일, 그림자, 수확·성장·특수 이펙트는 가능하면 분리한다. 단순한 이동, 스케일, 색 변화로 필요한 연출이 가능하면 엔진에서 처리할 수 있다.

농장 성장과 수확 범위 확대, 연쇄 수확은 화면에서 읽혀야 한다. 커서의 충전 표시와 실제 공격 타이밍은 일치해야 한다. 한 화면에서 이펙트가 겹쳐도 수확 대상, 남은 시간, 보상과 입력 가능한 UI를 가리지 않도록 한다.

## 4. UI 및 타이틀

- 한글 가독성이 중요하다. 기존 NotoSansKR TMP 에셋을 먼저 사용한다. 폰트 에셋을 수정할 때 필요한 글리프와 다른 씬에 미치는 영향을 확인한다.
- 배경/캐릭터/로고/버튼 장식을 분리해 교체할 수 있게 한다. 기존 그림을 무작정 늘리거나 찌그러뜨리지 않는다.
- 버튼에는 호버, 클릭 및 키보드 선택 피드백이 있어야 한다. 장식 이미지의 Raycast Target은 필요 없으면 끈다.
- 게임 메뉴는 게임 시작 / 옵션 / 회고록 / 나가기. 옵션과 회고록은 타이틀 내부 패널로 열고 돌아오기 동작을 제공한다.
- 마녀와 대악마를 함께 배치할 경우 단순히 스탠딩 두 개를 병렬로 놓기보다 서로의 시선, 자연스러운 구도와 여백을 고려한다.
- 새로운 UI 작업 전 기존 씬과 이미지 실제 모습을 확인한다. 레이아웃의 기준 해상도와 앵커는 화면 비율별로 검증하고, 좁거나 넓은 화면에서 중요한 메뉴가 가려지지 않게 한다.

### 현재 구현된 타이틀 (0.45)

`Assets/02.Scenes/TitleScene.unity`는 Codex가 작성한 씬이다. 1600×900 기준 Canvas, 좌측 로고/메뉴, 우측 기존 리엘 스탠딩, 달빛 농장 배경으로 구성된다. 이 구성은 현재 구현이며 모든 향후 화면에 동일 배치를 강제하지 않는다.

| 실제 리소스 경로 | 역할 |
| --- | --- |
| `Assets/07.Ui/Title/MoonlitFarm.png` | 타이틀 배경 |
| `Assets/07.Ui/Title/WitchHarvestLogo.png` | 로고 |
| `Assets/07.Ui/Title/MenuDetails.png` | 버튼 바탕, 아이콘과 별 장식이 포함된 스프라이트 시트 |
| `Assets/07.Ui/폰트/NotoSansKR-VariableFont_wght SDF.asset` | 기존 한글 TMP 폰트 |

기존 스탠딩 및 배너 참고 이미지는 사용자가 관리한다. 리소스의 Git LFS 포인터만 읽은 경우 실제 이미지의 화풍이나 품질을 평가할 수 없다. 새로운 일러스트가 필요하면 기존 자료를 직접 참고하거나 사용자에게 요청한다.

## 5. 제작·검수

AI로 제작한 아트는 원본을 보관하고 교체할 부분만 수정한다. 픽셀화 도구 및 수동 윤곽 보정은 검토 중인 파이프라인이며 표준으로 확정하지 않았다. 이미지 생성 결과를 실제 Unity 스프라이트로 가져올 때 투명도, Import 설정, Sprite Mode, 크기, 참조 및 게임 내 표시를 확인한다.

실제 화면에서 색감과 배치, 메뉴 선택 피드백, 캐릭터의 비율, 글자 잘림, 16:9 및 다른 화면 비율을 확인한다. 아트 수정 범위와 기존 디자인에서 바꾼 점을 설명한다. 실행/이미지 확인이 불가능하면 그 한계를 명시한다.
